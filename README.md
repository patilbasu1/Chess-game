# Chess Game

An interactive chess game that runs in your web browser. Play against another person on the same device or challenge the computer.

## Features

- Player vs. Player and Player vs. Computer modes
- Normal, Hard, and Expert difficulty options
- Light, Dark, and Classic themes
- Move hints and a move history
- Captured-piece display and turn/game status
- Pawn promotion, castling, and en passant
- Check, checkmate, stalemate, the 50-move rule, and threefold repetition
- Responsive layout for smaller screens

## Getting Started

No installation or build step is required.

1. Download or clone this project.
2. Open `index.html` in a modern web browser.
3. Choose a game mode, difficulty, and theme to start.

The game is implemented with plain HTML, CSS, and JavaScript. The main files are:

- `index.html` — game page and interface
- `style.css` — layout and visual themes
- `chess.js` — game rules and behavior

## How to Play

- Select a piece to see its available moves.
- Choose a highlighted square to move the piece.
- Use **Get Hint** for a suggested move.
- Use **New Game** to restart or **Back to Menu** to change game settings.
- When a pawn reaches the opposite end of the board, choose a piece for promotion.

In Player vs. Player mode, both players share the same board and take turns. In Player vs. Computer mode, play as White against the computer.
